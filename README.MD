CloudOps Sentinel

Intelligent Cloud Monitoring & Incident Management Platform

CloudOps Sentinel is an educational portfolio project designed to monitor application services, detect unusual system metrics using machine learning, and manage operational incidents.

Technology Stack

Frontend: React + TypeScript

Backend: C# + ASP.NET Core Web API

Database: Microsoft SQL Server

Machine Learning: Python + Scikit-learn

ML API: FastAPI

Deployment: Docker and Azure

CI/CD: GitHub Actions
